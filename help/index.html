How Pawsby works

1. The cat #

Once you finish setup, the cat lands on the bottom of your screen and starts wandering. It walks the floor of the screen and, by default, along the top edges of your open windows.

Do thisWhat happens
Click onceYou pet it. Mood goes up a little and it reacts.
Double-clickOpens the chat box. This is how you talk to it.
DragPicks the cat up. Let go over a window's top edge and it lands there; let go in mid-air and it falls to the floor.
Right-clickOpens the action menu — see §4.
Leave it aloneIt walks, sits, and occasionally says something on its own. Its mood drifts with how much you interact.

The click / double-click split is deliberate: a single click is a pat, so you can nudge the cat without a chat box popping up every time.

2. Talking to it #

Double-click the cat, type, press Enter. The reply appears in a speech bubble next to the cat and disappears after a few seconds (you set how long in Settings → Chat). Long replies split across pages — click the bubble's arrow for the next one.

On paid plans it can also search the web, so "will it rain tonight" or "who won last night" gets a current answer rather than a guess. Set your location in Settings → Chat so weather questions don't need a city every time.

The chat box comes in three styles (Settings → Chat → Chat Overlay Style):

  • Bubble — a compact input that closes as soon as you send. The default.
  • Classic — a small chat window with your message history and quick-reply buttons.
  • Transparent — frameless bubbles that stack upward and stay open.

Each message is capped at 2,000 characters. The chat box closes when it loses focus.

3. Slash commands #

Type any of these into the chat box and press Enter. They're handled locally, work on every plan, and don't use a chat from your daily count.

CommandThe cat…
/playplays for a moment, then goes back to what it was doing
/sleepcurls up on a cushion and stays asleep until you pick it up or send another command
/eateats
/stretchstretches
/boredlooks bored for a couple of seconds
/idle or /sitstops and sits still

Commands are case-insensitive. Anything else you type goes to the AI as normal.

4. Right-click and tray #

Right-click the cat for the same actions as the slash commands — Relax, Play, Sleep, Eat, Stretch, Bored — plus Sit Still / Walk, which toggles whether it wanders at all.

The tray icon (Windows: bottom-right near the clock; macOS: top-right menu bar) has:

  • Settings — opens the settings window
  • Focus Mode — sends the cat to a corner to sleep so it stays out of your way
  • Pause — freezes it in place
  • Quit

5. Settings #

Open from the tray icon. Eight tabs. Most changes apply when you press Save; the AI Settings and Sync tabs apply immediately.

Pet

  • Name — what it's called. The AI uses this as its own name.
  • Appearance — Russian Blue, Abyssinian, British Shorthair, Persian, plus any custom sprites you've imported (§9).
  • Personality — Calm, Playful, Logical or Gentle. Sets the tone of every reply.
  • Advanced — a free-text box added on top of the personality. "Always answer in one line", "you're a pirate", that sort of thing.

Chat

  • Your Name — how the cat addresses you.
  • Chat Language — Auto (matches whatever you type), or force English, 한국어, 日本語, 中文, Español, Français.
  • Your Location — used for weather and local questions.
  • Bubble Duration — how long a reply stays on screen, 3–30 seconds.
  • Chat Overlay Style — Bubble / Classic / Transparent (§2).
  • Quick Replies — three one-tap messages shown in Classic style.
  • View / Export / Delete History — your whole chat log, exportable as JSON or Markdown. Delete is permanent.

AI Settings

  • Current Plan — your tier and a Manage button that opens your billing portal (§10).
  • AI Mode — use the app's built-in AI, or your own API key (§8). Both need a paid plan.
  • Daily Usage — how many chats you've used today.

Display

  • Move Speed — Off / Slow / Normal / Fast. Off means it stays put.
  • Pet Size — 0.5× to 2.0×.
  • Focus Mode — the same as the tray toggle, plus an optional schedule so it turns on by itself between two times each day.
  • Pet Can Walk On — Floor and Windows, or Floor Only if you'd rather it never climbs on your windows.

Productivity

Calendar connection and alert timing — see §6.

Sync

Cloud sync between your devices — see §7.

Accessibility

  • Reduce Motion — the cat stops walking and animates at a very low frame rate.
  • High Contrast — black-and-white bubbles and chat box.
  • Font Size — 10px to 20px for bubbles and chat.

System

  • Launch at Login
  • App Language — English, 한국어, 日本語. Changes the whole interface immediately. (Separate from Chat Language, which is what the cat replies in.)
  • Theme — Light, Dark, or follow the system.
  • Updates — automatic check on/off, and a Check Now button (§11).
  • Version, links to Privacy Policy, Terms of Service and Delete My Account.

6. Calendar reminders Standard · Pro #

Settings → Productivity → Connect Google or Connect Outlook. Your browser opens to sign in; when you're done it sends you back to the app.

Once connected, tick Enable Calendar Alerts and pick Alert Before: 5, 10, 15 or 30 minutes. Before each event the cat pops up a bubble with the event name, and — if you've allowed notifications — a system notification too.

The cat only sees your upcoming events. It never reads event bodies, attendees, or anything else. Disconnect any time from the same tab.

Windows: if alerts appear in the app but not as notifications, check Settings → System → Notifications → Pawsby is allowed. The app re-checks when you come back to it.

7. Cloud sync Standard · Pro #

Off by default. Turn it on in Settings → Sync → Enable Sync; you'll see a short consent screen first. Then:

  • Your chats and settings are encrypted on your device before upload. The server stores ciphertext it cannot read.
  • Give each device a Device Name so you can tell them apart.
  • Auto-sync toggles for conversations and settings separately; or push a manual sync with the buttons.
  • Connected Devices lists every device on your account with a Remove button. Standard syncs 2 devices; Pro has no limit.
  • Delete All Cloud Data wipes the server copy. Your local history is untouched.

Sync runs in the background while you work, and again right after your computer wakes from sleep.

8. Your own API key Standard · Pro #

If you'd rather the cat talk to your own AI account, Settings → AI Settings → Use My Own Key (BYOK).

  • Provider — OpenRouter, Anthropic, OpenAI or Groq.
  • API Key — pasted once, encrypted and stored only on this device. It's sent straight to the provider you chose, never to our servers.
  • Model — pre-filled with a sensible default per provider; change it if you like.
  • Test confirms the key works before you save.

In BYOK mode your daily chat count doesn't apply — you're paying the provider directly. Web search and calendar still work.

9. Custom sprites Standard · Pro #

Settings → Pet → Appearance → + to import your own sprite sheet. Pawsby reads the Codex pets format as-is: an 8×9 grid of 192×208 cells, PNG or WebP. There's a growing library at codexpets.org; each sheet belongs to its creator, so check the usage terms where you download it.

Imported sprites show up next to the built-in breeds. Hover one to rename or delete it.

Prices are on the pricing page. To subscribe: Settings → AI Settings → View Plans. Checkout is handled by Creem, our merchant of record; if you have a promo code, there's an Add discount code link on the checkout page under the subtotal.

Manage (Settings → AI Settings) opens your billing portal, where you can see your next charge, change your card, switch between monthly and yearly, or cancel. Cancelling keeps your plan until the end of the period you've paid for, then drops to Free. Your chat history stays on your machine either way.

Moving to a new computer? Install Pawsby, and on the "Welcome back?" step choose I have a subscription. Enter the email you paid with and the one-time code we send, and your plan follows you. If you turned sync on, you can bring your chats and settings across in the same step.

11. Updates #

Pawsby checks for updates on its own (Settings → System to turn that off). When one is waiting, the cat says so in a bubble that stays until you dismiss it — double-click the cat to install and restart, or use the Install Update button in Settings → System.

12. If something's wrong #

  • Windows said the installer "isn't commonly downloaded" — that's SmartScreen's reputation check, which every new app trips until enough people have installed it. The installer is signed by IT TEC. Click More info → Run anyway.
  • The cat is gone — check the tray icon isn't paused, and Settings → Display → Move Speed isn't Off with the cat parked off-screen. Quitting from the tray and relaunching resets its position.
  • It stopped answering — Settings → AI Settings shows your daily count. On Free that's 3; it resets at midnight UTC. If you're on a plan and it's the model being slow, it retries once automatically.
  • "Reconnect calendar" — the sign-in expired. Settings → Productivity → Disconnect, then Connect again.
  • Sync says device limit reached — Standard allows 2. Remove an old device under Connected Devices, or move to Pro.
  • Anything else — support@pawsby.app. Say which OS you're on and roughly what you were doing; the app version is in Settings → System.
